# Analysis code for "Beyond Written Rules: Institutional Failures and Reform Priorities in China's Ethics Governance of Pediatric Gene Editing"

This repository contains the analysis code for the ChiCTR registry audit component of the manuscript (submitted to *BMC Medical Ethics*). The dataset is available on the Open Science Framework: https://osf.io/vp6ny/.

## Contents

| File | Description |
|------|-------------|
| `chictr_analysis.ipynb` | Jupyter notebook reproducing all registry-based statistics |

## Requirements

- Python 3 (tested with pandas 2.x, numpy 2.x, SciPy)
- Jupyter (notebook) / JupyterLab

Install: `pip install pandas numpy scipy matplotlib jupyter`

## Running the analysis

1. Obtain `ChiCTR.xlsx` (raw extraction sheet, 48 records pre-screening) and set `DATA_PATH` in the notebook to its location. The notebook performs screening, duplicate removal, and coding, and exports `chictr_included_studies.csv` (23 unique trials) at the end.
2. Run all cells top to bottom.

The notebook performs, in order:

1. Data loading and missing-value check
2. Inclusion/exclusion screening (ex vivo TCR-T/CAR-T removal, non-interventional removal, **duplicate removal**)
3. Variable coding (period, approval-to-registration interval, binaries, funding category, phase standardisation)
4. IIT/IND three-level classification (explicit markers → decision matrix → manual review)
5. Descriptive statistics: Table 2a/2b, Table S1 (funding source), Table S2 (pathway), DSMB-by-phase, interval distributions
6. Fisher's exact tests for between-period comparisons
7. Figures: interval distributions, DSMB-by-phase chart

All numbers reported in the manuscript are generated by this notebook.

## Reproducibility notes

- Period cutoff: 2023-03-01 (reform date).
- Interval = registration date − ethics approval date; one record with a placeholder approval date (1990-01-01) is treated as missing (interval n = 22).
- DSMB coding: 有 = 1; 无 or 暂未确定 = 0 (conservative).
- Wilson 95% CIs for proportions; Clopper-Pearson exact CIs where noted.
